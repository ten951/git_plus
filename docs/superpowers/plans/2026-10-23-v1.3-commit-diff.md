# V1.3 Commit Diff Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** 从悬浮卡片打开IDEA原生Diff，查看归属提交对当前文件的修改。
**Architecture:** 延用现有Inlay/Popup。Blame行保留porcelain的历史filename；点击卡片按钮后冻结仓库、SHA和历史路径，在后台通过Git4Idea获取Change，使用原生ShowDiffAction打开。加载任务独立于关闭的悬浮卡片，随编辑器/项目销毁取消。
**Tech Stack:** Kotlin、IntelliJ Platform 253/263、内置Git4Idea、协程；不增加第三方依赖。
**Spec:** 本文范围及当前会话用户要求（直接实现、测试、打包，无需反复确认）。

## Global Constraints
- V1/V1.2行尾显示、72小时规则、400ms悬浮、纯文本详情均保留。
- 固定比较提交与第一父提交；首次提交左侧为空。改名使用历史路径；缺失/浅克隆不可用对象明确提示，不自动fetch。
- 不显示未提交行的Diff入口；不增加设置页或整提交文件列表。
- Git查询不在EDT；Diff展示在EDT；关闭Popup不得取消用户已点击的Diff请求。
- 不修改用户Git配置，不push/合并；沿用当前干净功能分支v1.1-stability和已授权的当前工作目录。

## Review Focus
- 当前文件在Blame提交后改名：必须使用porcelain历史filename。
- merge/root提交：第一父提交/空内容，不能与工作区或其他父提交混淆。
- 引号、空格、非ASCII路径：Git路径解码后精确匹配，拒绝越界路径。
- 关闭Popup与加载竞态：点击捕获请求之后加载继续；编辑器销毁后禁止开窗。
- 未提交/不可用对象：无错误入口、无静默失败或自动网络操作。
